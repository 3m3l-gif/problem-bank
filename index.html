📐 수학 문제 저장소 · 처음 설정

문제를 내 Google 드라이브에 저장하려면, Google에서 발급하는 클라이언트 ID가 한 번 필요합니다. (무료, 5분)

  1. Google Cloud 콘솔에서 새 프로젝트를 만듭니다 (이름 예: 문제저장소).
  2. Google Drive API 페이지에서 사용을 누릅니다.
  3. Google 인증 플랫폼 → 시작하기: 앱 이름·이메일 입력, 대상은 외부.
  4. 같은 화면의 대상(Audience) → 테스트 사용자에 내 Gmail 주소를 추가합니다.
  5. 클라이언트 → 클라이언트 만들기 → 유형 웹 애플리케이션 → 승인된 JavaScript 원본에 를 추가하고 만듭니다.
  6. 만들어진 클라이언트 ID (…apps.googleusercontent.com)를 아래에 붙여넣습니다.

이 ID는 비밀번호가 아니라 앱 이름표 같은 것이라 공개되어도 괜찮습니다. 저장소 주인이 config.js에 넣어두면 이 화면 없이 바로 로그인됩니다.
